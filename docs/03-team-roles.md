## Кто что апрувит

| Что меняется | Обязательный ревьюер |
|---|---|
| Любой MR в `develop` | 1 участник команды, не автор |
| Архитектура, схема БД, формат блоков и хешей | Архитектор |
| Dockerfile, docker-compose, конфиги | DevOps (Архитектор) |
| Требования, US/UC | Аналитик |
| Документация | Тех. писатель |
| MR из `develop` в `main` (релиз) | Lead |

## RACI по ключевым артефактам

R — делает, A — отвечает за итог, C — консультирует, I — информируется.

| Артефакт | Lead | Аналитик | Архитектор/DevOps | Тех. писатель/QA |
|---|---|---|---|---|
| Требования FR/NFR, US, UC | A | R | C | I |
| Архитектура, формат данных | C | C | A/R | I |
| Бэклог и спринт-план | A/R | C | C | C |
| Код фич | A | I | C | I |
| Тест-кейсы и тестирование | I | C | C | A/R |
| Docker/локальный стенд, развёртывание | I | I | A/R | C |
| Документация | I | C | C | A/R |
| Релиз в `main` | A/R | I | C | C |
