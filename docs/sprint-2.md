# Спринт 2 — ядро блокчейна

Цель: рабочее ядро: хеширование BLAKE2b-256, классы записи, блока и цепочки, хранение цепочки в JSON-файле, проверка целостности цепочки, тесты. Основа — `02-architecture.md`, раздел 18.

В этот спринт не входят: Merkle root, Proof-of-Work, `GetProof`, пул записей с формированием блока по таймеру, хранение цепочки в PostgreSQL. Хранилище закрыто интерфейсом `IChainRepository`, поэтому позже его можно заменить на PostgreSQL, не трогая ядро.
